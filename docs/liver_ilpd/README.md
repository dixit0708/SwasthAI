# Liver Disease Risk — Lab-Based (ILPD) Endpoint

Backend documentation for `POST /api/v1/predict/liver-ilpd`. This is the
"I have my lab report" counterpart to `POST /api/v1/predict/liver`
(liver-nhanes-v1, lab-free) — a separate, independently trained model.
Their outputs are never blended or averaged.

## Model

- **Version:** `liver-ilpd-logistic-v1`
- **Artifact:** `ml_pipeline/liver/artifacts/liver_ilpd_logistic_v1.pkl`
  (a single sklearn Pipeline: median imputer + scaler + one-hot encoder +
  Logistic Regression)
- **Metadata:** `ml_pipeline/liver/artifacts/liver_ilpd_logistic_metadata_v1.json`
- **Dataset:** canonical UCI ILPD (Indian Liver Patient Dataset), 583 raw
  rows, 570 after removing 13 exact duplicates. Source, class balance,
  and full methodology: `ml_pipeline/liver/reports/ilpd_final_model_report.md`.
- **This artifact is locked.** `backend/app/ai/models/liver_ilpd_model.py`
  verifies its SHA-256 checksum before loading and refuses to start the
  model if either the pipeline or metadata file has drifted from the
  validated version. It must not be retrained, and its preprocessing or
  threshold must not be changed, without re-running the full validation in
  the report above and re-locking a new checksum.
- **Not used:** the 30,691-row "LPD" dataset/model
  (`ml_pipeline/liver_lpd/`) — rejected for showing strong evidence of
  synthetic/rule-generated labels; see
  `ml_pipeline/liver_lpd/reports/data_integrity_investigation.md`.

## Request

`POST /api/v1/predict/liver-ilpd` — requires the same bearer-token
authentication as every other `/predict/*` route.

```json
{
  "age": 45,
  "gender": "Male",
  "total_bilirubin": 1.2,
  "direct_bilirubin": 0.4,
  "alkaline_phosphatase": 187,
  "alt_sgpt": 42,
  "ast_sgot": 38,
  "total_proteins": 6.8,
  "albumin": 3.4,
  "albumin_globulin_ratio": 1.0
}
```

Schema: `LiverIlpdPredictionInput` (`backend/app/models/prediction.py`).
`age` and `gender` are required; every other field may be submitted as
`null` — the model's own imputer (fit at training time) supplies a
missing lab value, mirroring what the training dataset itself required
(4 of 570 rows had a missing `albumin_globulin_ratio`). A field that is
present but invalid (wrong type, out of clinical range) is still
rejected — `null` is only accepted where a value is genuinely absent.
`extra="forbid"` rejects any field not listed above, including the
dataset's own target column (`Selector`) or any other unsupported
variable.

## Response

Reuses this project's existing `RiskPredictionOut` shape (the same one
`/predict/diabetes`, `/predict/liver`, and `/predict/diabetes-pima`
return):

```json
{
  "risk_level": "screening_elevated",
  "risk_probability": 0.62,
  "threshold": 0.35,
  "is_elevated": true,
  "message": "Your inputs show elevated risk indicators for liver disease based on this screening model. This is not a diagnosis — please discuss these results with a qualified healthcare professional.",
  "model_version": "liver-ilpd-logistic-v1",
  "disclaimer": "This is an AI-generated risk indicator based on the values you entered, not a medical diagnosis. Please consult a qualified healthcare professional to discuss these results and any next steps."
}
```

`risk_probability` is an estimated probability, never described as a
diagnosis or "diagnosis confidence." The disclaimer is generated by
`app/ai/safety/response_filter.build_screening_response()`, the same
function every other structured-data model routes through, per AGENTS.md
Section 11.

## Errors

| Status | Cause |
|---|---|
| 401 | Missing/invalid auth token |
| 422 | Missing required field, wrong type, out-of-range value, invalid `gender`, malformed JSON, or an unexpected extra field |
| 503 | Model not loaded (startup failure, including a checksum mismatch on the locked artifact) |
| 500 | Unexpected inference failure — logged server-side; no stack trace, file path, or internal model detail is returned to the client |

## Intended use and limitations

- Informational and educational only — **not a medical diagnostic
  device**, not a doctor replacement, and its output is never described as
  a guaranteed, confirmed, or clinically proven diagnosis.
- Trained on a small (570-row), single-region population (Northeast
  Andhra Pradesh, India; 441 male / 142 female in the raw file) —
  predictions for users outside this population should be treated with
  added caution.
- No external clinical validation has been performed.
- Full limitations: `ml_pipeline/liver/reports/ilpd_final_model_report.md`
  Section 14.
