# DermNet Skin Disease Dataset

This directory is intended to house the dataset for training the Skin Disease CNN detector. 

**Note: The actual dataset images are excluded from version control to prevent bloating the Git repository.**

## How to get the dataset
We use the **DermNet** dataset (originally from DermNet NZ) via Kaggle, which contains thousands of images across 23 different skin disease classes.
1. Download the dataset from: [https://www.kaggle.com/datasets/shubhamgoel27/dermnet](https://www.kaggle.com/datasets/shubhamgoel27/dermnet)
2. Extract the archive.
3. Place the `train` and `test` folders directly inside this `data/` directory.

## Expected Directory Structure
```text
ml-services/skin-disease-detector/data/
├── README.md
├── split_manifest.csv      # Generated by our custom splitting logic
├── train/
│   ├── Acne and Rosacea Photos/
│   ├── Melanoma Skin Cancer Nevi and Moles/
│   └── ... (21 other classes)
└── test/
    ├── Acne and Rosacea Photos/
    ├── Melanoma Skin Cancer Nevi and Moles/
    └── ... (21 other classes)
```

After placing the data here, you can run the `train.py` or evaluation scripts from the parent directory. The model relies on `split_manifest.csv` to ensure consistent data splitting across environments, including Colab.
